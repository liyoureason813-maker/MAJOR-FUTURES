# MAJOR FUTURES V4.2.2 — Content & Admissions Refresh

星海实验高级中学融致国际课程项目 · MAJOR FUTURES 专业选择系统。

## 本次更新（2026-10-28）

- 延续 V4.2.1.1 解决职业兴趣测评选择答案后页面跳顶的问题，未改动霍兰德60题与原匹配算法。
- 将“高危/骑线/安全”在用户界面改为“高暴露/转型/低替代”，明确：任务暴露度不等于就业流失预测，站内分数不是官方统计概率。
- 新增2027申请的 Oxford、UCL、LSE 官方附加测试速查，并在11类相关专业详情中展示对应**具体课程**的 Required/Recommended，链接官方规则。
- 增加三个职业成长阶段的学习问题（定性例子，不是经过数据验证的不同资历风险分数）。
- 新增 ILO 2026、WEF 2026 与 O*NET 31.0 等官方研究来源及核验日期。

## 数据边界（重要）

本次**没有**把站内28个专业/252个方向/756条岗位学历提示逐一映射到O*NET-SOC编码，也**没有**重新估计各岗位风险分值或学历要求。O*NET 31.0目前只是职业数据后续逐岗审校的最新官方基准。不能声称所有岗位已经按31.0完成核对。研究梳理不替代目标大学专业官网的逐年申请要求。

## 文件结构

- `index.html` 网页入口
- `styles.css` 样式
- `app.js` 专业数据、UI与2027入学测试示例
- `matcher.js` A-Level科目匹配
- `holland.js` 霍兰德测评，保留不跳顶修复

部署到GitHub Pages时，五个网页文件放在仓库根目录，`README.md`为说明文件。`index.html` 的缓存参数已统一为 `v=4.2.2`。
